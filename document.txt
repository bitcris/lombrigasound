1. VISÃO GERAL DO PROJETO
--------------------------------------------------------------------------------
O Lombrigasound é uma biblioteca estática de visualizadores de áudio leves e
reativos para Web Players, Rádios Online e Streams.

• Ambiente Linux: /home/station/orange-station/lombrigasound
• Hospedagem: Cloudflare Pages / Workers
• URL Base de Produção: https://lombrigasound.dnsx.workers.dev/
• Modo de Uso: Embutido via <iframe> em players externos.


2. ARQUITETURA SINGLE-FILE (ARQUIVO ÚNICO POR VISUALIZER)
--------------------------------------------------------------------------------
Cada visualizer deve ser implementado em um único arquivo HTML autocontido na
pasta do projeto (`/home/station/orange-station/lombrigasound`), com HTML, CSS e
JavaScript inline no mesmo arquivo.

• Nomenclatura das Rotas:
  - O arquivo `rock1.html` torna-se a rota `/rock1`
  - O arquivo `flashback1.html` torna-se a rota `/flashback1`
  - O arquivo `country.html` torna-se a rota `/country`

• Regras de Desempenho (Obrigatórias):
  1. Resolução leve: Usar DPR = 1 (canvas.width = window.innerWidth).
     Evitar multiplicações de telas 4K/Retina para manter consumo de GPU < 1%.
  2. Canvas em tela cheia com CSS `width: 100vw; height: 100vh; overflow: hidden;`.
  3. Redimensionamento responsivo com listener em `window.addEventListener('resize')`.
  4. Fundo limpo (preto ou escuro) e renderização via Canvas 2D ou WebGL leve.


3. PROTOCOLO DE COMUNICAÇÃO (postMessage)
--------------------------------------------------------------------------------
O player pai se comunica com o <iframe> através de `window.postMessage`.
Todo visualizer deve obrigatoriamente escutar e responder a 2 parâmetros:

  1. `isPlaying` (boolean):
     - `true`: A animação corre no ritmo normal do gênero.
     - `false`: A animação pausa ou entra em repouso estático.

  2. `genre` (string):
     - Estilos suportados: "synthwave", "rock", "country", "flashback", "lofi", "jazz".
     - O visualizer deve adaptar suas cores (paleta primária/secundária) e a velocidade
       conforme o gênero recebido.

Código padrão do listener:
```javascript
window.addEventListener('message', (e) => {
  if (!e.data) return;

  // 1. Play / Pause
  if (e.data.isPlaying !== undefined) isPlaying = Boolean(e.data.isPlaying);
  else if (e.data.playing !== undefined) isPlaying = Boolean(e.data.playing);

  // 2. Gênero Musical
  const rawGenre = e.data.genre || e.data.genere;
  if (rawGenre && typeof rawGenre === 'string') {
    genre = rawGenre.toLowerCase().trim();
  }
});
```


4. ARQUIVO DE REFERÊNCIA (TEMPLATE BASE)
--------------------------------------------------------------------------------
O arquivo de referência é:
`/home/station/orange-station/lombrigasound/exemplo.html`

Para criar um novo visualizer:
  1. Duplique `exemplo.html` com o novo nome (ex: `rock2.html`).
  2. Altere o algoritmo de desenho dentro da função `render()`.
  3. Adicione a nova rota na lista de rotas do `index.html`.
